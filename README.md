# Praksis hos Elefun

En enkel og minimalistisk nettside for UiA-praksisprosjektet PlukkeFun. Forsiden beskriver kort hva prosjektet går ut på og lenker til egne sider for oppgavebeskrivelse, prosjektdagbok, presentasjon, statusrapporter og avsluttende refleksjon.

Siden har en enkel nettleserbasert redigeringsmodus for lokale kladder. GitHub Pages er statisk, så kladder lagres bare på enheten og publiseres ikke automatisk.

Publisert med GitHub Pages.
