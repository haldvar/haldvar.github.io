# Praksis hos Spring Marketing

En enkel og minimalistisk nettside for UiA-praksisprosjektet hos Spring Marketing. Prosjektet er å utvikle PlukkeFun for Elefun. Forsiden beskriver kort hva prosjektet går ut på og lenker til egne sider for oppgavebeskrivelse, prosjektdagbok, studentpresentasjon, praksissted, statusrapporter og avsluttende refleksjon.

Publisert med GitHub Pages.
